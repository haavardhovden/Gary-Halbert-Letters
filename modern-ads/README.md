# modern-ads/

Curriculum seksjon 3: studie av topp paid social-brands via Atria ("inspo", sortert på
longest running / impressions). Én fil per brand: `modern-ads/<brand-slug>.md`.

Per annonse: hook/headline ordrett, format (static/UGC/video), hva den gjør og hvorfor det
virker, og eventuelt hvilken Halbert-mekanisme den er en moderne versjon av (`→ #N`).
Nye mønstre som ikke finnes i `mechanisms.md` logges der med `Kilde: modern-ads/<brand>.md`.

Brand-listen og avkryssing ligger i `curriculum.md`.

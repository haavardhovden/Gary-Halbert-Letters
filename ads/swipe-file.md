# ads/swipe-file.md

Index of the 9 classic ads from Halbert's "Hands On Experience" swipe canon — the list of
ads he tells the reader to obtain and hand-copy in `letters/letter-001.md` ("Hands On
Experience For A Basic Education In Advertising Principles!"). All 9 files below appear by
name in that letter's reading list.

Each ad has a scanned source (`ads/[name].pdf`) and a text transcription
(`ads/[name].md`) so the copy is usable without opening the PDF.

**Note on `mechanisms.md` status:** `mechanisms.md` now holds the real draft (from the
original Notion read-through), not the empty template — all 9 ads below already had an
entry in that draft. This file was updated to point at the actual entry numbers instead of
flagging them as gaps.

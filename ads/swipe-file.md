# ads/swipe-file.md

Index of the 9 classic ads from Halbert's "Hands On Experience" swipe canon — the list of
ads he tells the reader to obtain and hand-copy in `letters/letter-001.md` ("Hands On
Experience For A Basic Education In Advertising Principles!"). All 9 files below appear by
name in that letter's reading list.

Each ad has a scanned source (`ads/[name].pdf`) and a text transcription
(`ads/[name].md`) so the copy is usable without opening the PDF.

**Note on `mechanisms.md` status:** as of this writing, `mechanisms.md` is still an empty
template (headers only, no filled-in entries — see its own header note: "la Claude Code
fylle det ut ved re-vurdering"). So none of the 9 ads below actually have a populated
mechanisms.md entry yet — the "entry" column names the *intended* technique/slot each ad
would document once mechanisms.md gets filled in, not a live cross-reference. Two of the
nine (Admiral Byrd, Burn Off Body Fat) don't even have a technique name assigned yet, which
is the specific gap called out below.

# UGC / creator-format — swipe file

Ett spørsmål per innslag: **hva er det som gjør at denne IKKE ser ut som reklame?** (grunnprinsipp 1 / A-Pile #5)
Noter: skaper-type → setting/rot → første setning → hvor produktet dukker opp → hvorfor det ikke føles som salg.

## Prinsipper fra Halbert som gjelder UGC
- Rotet i bakgrunnen er tidsstempelet (#34). Studio = B-Pile.
- Irrelevant mikrodetalj ("den blå bandanaen") gjør fortelleren ekte (Boron kap. 23).
- Skaperen skal si det merkevaren ikke kan si om seg selv (Theresa-grepet, letter-112).
- Les manuset høyt — snubler skaperen, er manuset feil (#38).
- Sanselig, ikke seksuelt, på NAKEN-vinkelen (client-applications).
- "Kundene er tekstforfatterne": start med et ekte review-sitat som første linje.

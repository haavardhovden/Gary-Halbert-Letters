# Swipe files

Seks filer, ett formål: aldri starte fra blankt ark. Halberts regel (Boron kap. 10, 15, 17, 22):
samle bare det BESTE — annonser som beviselig har virket eller kjørt lenge — og les dem høyt,
skriv dem av, bruk dem som råstoff. Ikke "fin copy". Copy som solgte.

| Fil | Hva som går inn | Kriterium |
|---|---|---|
| `headlines.md` | Headlines/hooks | Stoppet deg, OG du kan si hvilken mekanisme den bruker |
| `bullets.md` | Fascinations/bullets | Åpen løkke + spesifikk + løfte. Ikke "features" |
| `sales-letters.md` | Hele brev/landingssider | Fullstendig AIDA, kjent resultat der det finnes |
| `static-ads.md` | Statics (paid social) | Kjørt >4 uker i Ads Library, eller egne vinnere med tall |
| `video-ads.md` | Video/animasjon | Første 3 sek + struktur notert, ikke bare lenke |
| `ugc.md` | UGC/creator-format | Hva gjør at den IKKE ser ut som reklame? Noter det |
| `facts.md` | Interessante fakta (mek. 42) | Sant, kildebelagt, RELEVANT for søvn/hud/temperatur/friluft |

Format per innslag: kilde/lenke → selve teksten → én linje: hvorfor den virker (mekanisme-nr fra
mechanisms.md der det passer) → evt. Stille/Vidda-vri.

# Oppsett: fire chatter, ett repo

Repoet er det felles minnet. Hver chat starter med å lese sin rollefil. Når noe besluttes,
skrives det i repoet, ikke bare i chatten.

| Chat (forslag til navn) | Rolle | Rollefil | Repo-tilgang |
|---|---|---|---|
| **1 Strategi** | Hva vi lager og hvorfor. Tall, vinnere, Black Week | `kreativ-strategi.md` | ja |
| **2 Copy** | Skriver batchene | `copywriting-machine.md` (+ `-FULL.md` hvis uten repo) | ja |
| **3 QA** | Sjekker hver batch mot alle regler før Jonathan | `strateg-feillogg.md` (selvstendig) | nei, lim inn |
| **4 Curriculum** | Leser brev, annonser, bøker. Fyller `mechanisms.md` | `CLAUDE.md` | ja |

Flyt: 1 Strategi → brief → 2 Copy → batch → 3 QA → Jonathan → feedback tilbake til 3 QA
(ny regel) og 2 Copy.

Første melding i hver chat: «Les `roles/<fil>.md` og følg den.»

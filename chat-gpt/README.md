# Chat GPT

Egen del for brev og oppdateringer fra samarbeidet med ChatGPT. Tidligere arbeid beholdes urørt.

## Arbeidsmåte

- Hvert brev brukeren sender lagres ordrett i `letters/`, med vurderingen separat i `updates.md`.
- Bruk beskrivende filnavn her. Ikke gjett neste nummer i det gamle arkivet: den sjekkede branchen har logg til 126, mens nyere overlevering viser videre fremdrift.
- Samme brev sendes ikke inn som et nytt brev når brukeren bare rydder formateringen. Da oppdateres eksisterende fil.
- Vurder lærdommer og dømmekraft, ikke bare nye mekanismer. Ikke presenter nye eksempler som nye mekanismer.
- Ingen endringer i tidligere klientnotater uten å foreslå dem først.
- Originaltekst og vurderinger holdes atskilt. Produktpåstander er ikke dokumentert bare fordi de står i et brev eller tidligere chat.

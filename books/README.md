# books/

Lesenotater per bok fra curriculum seksjon 4. Én fil per bok: `books/<slug>.md`.

Format per fil: kort oppsummering per kapittel (nøytral, uten tolkning), de sitatene som er
verdt å ha ordrett, og en linje per kapittel om det ga en ny mekanisme (`→ mechanisms.md #N`)
eller ikke. Ikke lim inn hele kapitler ordrett — dette er notater, ikke kopier av boka.

Mekanismer fra bøker går i `mechanisms.md` med `Kilde: <boktittel>, kap. X`. Samme bar som
for brevene: bare genuint nye mønstre.

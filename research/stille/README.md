# Stille-research (5. sept 2026)

Råstoff for headline-arbeid etter Halberts metode (Boron kap. 15: samle alt i én boks, nugget notes, stjernemerk).
Laget av research-agenter natt til 5. sept. Alt med ⚠️ eller "FORBEHOLD" må sjekkes mot kilde-URL før det brukes i en annonse.

- `01-repo-oppsummering.md` — alt repoet allerede visste om Stille: produktfakta (og hva som mangler), ekte kundesitater, testede vinkler, Jonathans regler, headline-mekanismene.
- `02-produkt-og-sovnfakta.md` — 45 fakta om bambusviskose/lyocell, sateng, OEKO-TEX, søvn og temperatur, væsketap per natt. Hver merket TRYGG / FORBEHOLD / IKKE BRUK.
- `03-segmentfakta.md` — overgangsalder, atopisk eksem, hot sleepers, kjæledyrhår, luksus/estetikk. Tall med kilder.
- `04-kundesprak.md` — 60+ ordrette kundesitater, norsk og engelsk, gruppert på segment. Konkurrent-sitater er markedsbevis, aldri sosialt bevis for Stille.

Viktigste hull funnet: repoet vet ikke om Stille selger viskose eller lyocell. Det avgjør "rund fiber", "puster bedre" og miljøargumentet. Spør kunden.

STATIC CONCEPTS FOR META PERFORMANCE MARKETING 
Context Document for Creative Production 20 Proven Concepts · Copy Guidelines · Usage Framework 
Curve March 2026 Static Concepts — Context Document How to Use This Document This document defines 20 static ad concepts for Meta performance marketing. Each concept has a specific purpose, a defined copy density level, and clear guidelines on how much text belongs on the image itself versus in the primary text field. The goal: every static we produce should have copy that fits the concept. No more walls of text on a Post-It Note. No more empty Article statics. The concept dictates the copy, not the other way around. 
Key Terminology • Angle: The overall messaging direction toward a specific persona. Example: “Painpoint angle for busy founders.” • Static concept: The visual format that communicates the angle. Example: “Post-It Note” or “Split Screen Comparison.” • On-image copy: Any text that appears as part of the static image itself (headline, subline, body text baked into the design). • Primary text: The caption text in the Meta ad unit (above the image). This is where longer copy lives when needed. • Copy density: How much text the concept can carry on the image before it breaks. Rated: Minimal, Low, Medium, High. 
The Copy Density Framework Not every concept can carry the same amount of copy. This is the core problem this document solves. Below are the four density levels and what they mean in practice.

General Copy Rules for All Statics These rules apply to every concept regardless of density level. 
On-Image Copy Rules • Headline is king. If someone only reads one thing, it should be the headline. • Write for a 2-second scan. The message must land without effort. • Use hierarchy: headline (large) > subline (medium) > supporting text (small). Never reverse this. • Front-load the benefit or hook. Don’t bury the lead. • No filler words. Cut “that,” “just,” “really,” “very” — every word must earn its place. • Avoid full sentences when a punchy phrase works better. • One message per static. If you’re trying to say two things, make two statics. • Never place critical text outside the 1:1 safe zone (centered in the 9:16 frame). 
Primary Text Rules (Caption) • Keep the most important message in the first 80 characters (before “See more”). • Use primary text to expand on the hook, not repeat it. • Match the tone to the concept: a Meme static doesn’t need a formal paragraph. • For low-density concepts, short primary text (1–2 lines) is often best. • For high-density concepts, you can go longer in primary text, but still lead with a hook. • Always write 3–5 primary text variations so Meta can optimize delivery. 
Safe Zone Reminder All statics are produced in 9:16 format with content inside a 1:1 safe zone. This means the actual usable design area for critical text is a centered square. Headlines and key copy must live inside this zone. Decorative or non-essential elements can bleed into the full 9:16 frame.

1. POST-IT NOTE Copy density: MINIMAL Max on-image copy: 1–5 words WHEN TO USE Curiosity-driven hooks. TOF awareness. When you want to stop the scroll with intrigue. Works great for simple questions or bold claims that make people want to learn more. DESIGN NOTES A Post-It Note (or similar sticky note) covers or sits next to the product/visual. The note contains one short handwritten-style phrase. Background should be simple — product shot, flat color, or lifestyle image. The note IS the hook. COPY GUIDELINES This is the most minimal concept. The Post-It carries ONE thought: a question, a claim, or a single provocative phrase. Nothing else. Any explanation lives in the primary text. DO + Use a single question or bold statement + Keep it conversational and intriguing + Let the product behind the note do the rest + Use handwriting-style font on the note DON’T - Write a paragraph on the Post-It - Add sublines or bullet points - Explain the product on the note - Use formal or corporate language 
2. SNAPCHAT / DM SCREENSHOT Copy density: LOW Max on-image copy: 5–12 words WHEN TO USE Social proof through perceived authenticity. Works across all funnel stages. Best for testimonial angles, “where did you get that” moments, and relatable peer conversations. High trust factor. DESIGN NOTES Mimics a Snapchat message, iMessage, WhatsApp, or DM conversation. Use realistic UI elements (chat bubbles, timestamps, read receipts). The conversation should feel genuine, not scripted. One screenshot, not a thread. COPY GUIDELINES The copy IS the conversation. Keep it to 2–4 short chat messages max. Each message should be casual, short, and sound like a real person texting. No one sends paragraphs in a DM. DO + Use casual language and abbreviations + Keep each message to one short line DON’T - Write long formal messages in chat bubbles - Include more than 4–5 messages Page 4 Static Concepts — Context Document + Make the conversation feel like it happened organically + Include subtle UI details for realism - Add captions or headlines on top of the screenshot - Use perfect grammar — real DMs are messy 
3. SPLIT SCREEN COMPARISON (PROBLEM/SOLUTION) Copy density: MEDIUM Max on-image copy: 15–25 words WHEN TO USE Mid to bottom funnel. When you need to show a clear contrast between the problem state and the solution, or when the product’s benefit is best explained through contrast. Strong for objection-handling angles. DESIGN NOTES Frame divided into two halves (vertical or horizontal split). Left/top = problem or “without,” right/bottom = solution or “with.” Use contrasting colors (red vs green, dark vs light). Visual difference should be instantly obvious. COPY GUIDELINES Each side gets a short headline (2–5 words) and optionally 1–2 bullet points. The contrast in copy should mirror the visual contrast. Keep both sides equally balanced in text volume. DO + Use clear visual contrast between the two sides + Keep headlines parallel in structure + Make the “with” side obviously more appealing + Use icons or checkmarks/X marks for quick scanning DON’T - Overload one side with text - Use paragraphs — stick to bullets or phrases - Make the two sides look similar - Bury the product name — it should anchor the solution side 
4. US VS THEM Copy density: MEDIUM Max on-image copy: 15–25 words WHEN TO USE Competitive positioning. Bottom funnel where prospects are comparing options. Best when your differentiator is clear and can be shown in a side-by-side format. Use when the audience already knows the category. DESIGN NOTES Two-column or two-row layout comparing your brand against alternatives (can be generic or named competitors). Use brand colors on your side, muted/grey on theirs. Checkmarks vs X marks are the universal language here. COPY GUIDELINES Column headers + short comparison points. Each row should be one feature or benefit — maximum 5–6 rows. Labels should be 1–3 words each. Don’t explain, just state. 5. BEFORE / AFTER Copy density: LOW Max on-image copy: 5–15 words WHEN TO USE Transformation-based angles. Works for skincare, fitness, SaaS dashboards, home improvement, anything with a visible result. Strong at all funnel stages because transformation is universally compelling. DESIGN NOTES Side-by-side or top/bottom showing the before state and after state. Labels should be clear (“Before” / “After” or time-based: “Day 1” / “Day 30”). The visual transformation does the heavy lifting. COPY GUIDELINES Minimal text needed. “Before” and “After” labels plus an optional one-line headline. Let the imagery tell the story. If you need to explain the transformation, it’s not visual enough. DO + Let the visuals carry the message + Use clear, simple labels + Show real or realistic results + Add a timeframe for credibility DON’T - Add paragraphs of explanation - Use stock photos that look fake - Overclaim — Meta will reject exaggerated before/afters - Forget to label which is before and which is after 
6. ARTICLE / EDITORIAL Copy density: HIGH Max on-image copy: 30–60 words WHEN TO USE Authority and education-based angles. Best for TOF and MOF where you need to establish credibility, share insights, or position the brand as a thought leader. Works well for complex products or services. DESIGN NOTES Mimics a news article, blog post, or editorial layout. Large headline at top, byline or source, body text below. Can include a small product image or brand logo. Use clean serif or editorial-style fonts. COPY GUIDELINES Page 6 Static Concepts — Context Document This is one of the FEW concepts that can carry significant text. Write a compelling headline (5–10 words), a subline (10–15 words), and 1–2 short paragraphs or key points. But even here, less is more — this is an ad, not an actual article. DO + Write a click-worthy editorial headline + Include a credible source or byline + Use editorial typography to set the tone + Keep body text scannable with short paragraphs DON’T - Write an actual full article on the image - Use marketing language — it should feel journalistic - Forget a clear CTA - Make it look like a fake news article in a deceptive way 
7. IG STORY SCREENSHOT Copy density: LOW Max on-image copy: 5–15 words WHEN TO USE Social proof and native-feeling content. Works across all funnels. Best when you want the ad to feel like organic content someone shared, not a polished ad. High trust signal. DESIGN NOTES Mimics an Instagram Story with the story UI elements (profile pic, username, timestamp, reply bar at bottom). Content looks like a real person posted it. Can include photo, text overlay, stickers, polls. COPY GUIDELINES Whatever a real person would type on their IG Story. Short, casual, often with emojis. One line of text overlay, maybe two. Think “obsessed with this” not “This product has 5 key benefits.” DO + Use realistic IG Story UI elements + Keep the language casual and first-person + Make it look like a real Story, not a designed ad + Use one reaction sticker or emoji for authenticity DON’T - Over-design it — it should look native - Write multiple lines of text - Include a formal headline or subheadline - Remove the Story UI elements that make it believable 
8. TESTIMONIAL / REVIEW CARD Copy density: MEDIUM Max on-image copy: 15–30 words WHEN TO USE Bottom funnel social proof. When you have strong customer quotes, 5-star reviews, or specific results. Best for overcoming trust objections and validating purchase decisions. DESIGN NOTES Page 7 Static Concepts — Context Document Clean card layout with a quote, star rating, customer name/photo (optional), and brand logo. Background should be simple. The quote should be visually dominant. Can mimic review platforms (Trustpilot, G2, etc.). COPY GUIDELINES Lead with the most powerful part of the review. Pull the best 1–2 sentences max. Bold or highlight the key phrase. Don’t use the full review — extract the most compelling fragment. DO + Pull the single best sentence from the review + Bold the key result or claim + Include star rating for instant credibility + Use real names and photos when possible DON’T - Paste the entire review - Use generic quotes like “Great product!” - Fabricate or edit reviews - Crowd the card with multiple reviews 
9. PRODUCT HERO Copy density: LOW Max on-image copy: 3–10 words WHEN TO USE Bottom funnel purchase intent. When the product itself is the selling point and you want to showcase it beautifully. Best for launches, new flavors/colors, or when the product is visually compelling. DESIGN NOTES Product takes center stage with premium photography or 3D render. Minimal design elements. Clean background (solid color, gradient, or subtle lifestyle context). The product should occupy 50–70% of the safe zone. COPY GUIDELINES Headline or tagline only. The product IS the content. A short, punchy phrase that reinforces why it’s great, or just the product name + one benefit. Nothing more. DO + Let the product be the star + Use high-quality imagery + Add one strong tagline or benefit statement + Keep the background clean and non-distracting DON’T - Add paragraphs of features - Use multiple text elements - Let the product get lost in a busy background - Use low-quality or generic product photos 
10. STAT / DATA CALLOUT Copy density: LOW Max on-image copy: 5–15 words WHEN TO USE Authority angles and proof-based messaging. Best for TOF/MOF when you have a compelling number that stops the scroll. Works for credibility, scale, or results-based positioning. DESIGN NOTES Page 8 Static Concepts — Context Document One dominant number or statistic takes up most of the visual space. Supporting context text is much smaller. Use contrasting size hierarchy — the number should be 3–4x larger than any other text. Can include a simple icon or chart element. COPY GUIDELINES The number is the hero. One stat + one line of context. Example: “93%” big, “of users saw results in 14 days” small below. That’s it. The primary text does the explaining. DO + Make the number visually dominant + Use a specific, credible number + Add minimal context text + Source the stat in primary text DON’T - Use multiple statistics - Make the context text compete with the number - Use vague or rounded numbers - Forget to provide a source somewhere 
11. QUOTE CARD Copy density: LOW Max on-image copy: 8–20 words WHEN TO USE Founder/CEO messaging, thought leadership, or motivational angles. Best when the brand has a strong personal voice or when quoting an industry figure to borrow authority. DESIGN NOTES Quote marks (large, decorative), the quote text, and attribution (name, title, photo). Clean background. The quote should be the visual focus. Can use the person’s photo as background with overlay. COPY GUIDELINES One quote. One sentence, ideally. Maximum two short sentences. The quote should be memorable, specific, and sound like a real person said it. Avoid generic motivational fluff. DO + Use a genuine, specific quote + Include proper attribution + Use large decorative quotation marks + Pick quotes that have a strong opinion or insight DON’T - Use long multi-sentence quotes - Use generic or cliché motivational text - Forget attribution - Combine multiple quotes on one card 
12. MEME / RELATABLE Copy density: MINIMAL Max on-image copy: 2–8 words WHEN TO USE TOF scroll-stopping and brand personality. When the angle is about shared experiences or frustrations. Best for awareness, engagement, and making the brand feel human. Works especially well for younger audiences. Page 9 Static Concepts — Context Document DESIGN NOTES Uses a recognizable meme format, reaction image, or relatable scenario. The format should be immediately recognizable. Text follows meme conventions (top text / bottom text, or caption above image). Lo-fi is fine — this should NOT look polished. COPY GUIDELINES Meme copy is extremely short by nature. The humor or relatability must land in under 5 words per text element. If you need to explain the joke, pick a different concept. DO + Use a recognizable meme format + Keep text ultra-short + Make sure the joke/relatability lands instantly + Match the brand’s humor to the audience DON’T - Overexplain the joke - Use a meme format nobody recognizes - Force the brand into the meme unnaturally - Add CTAs or product details to a meme 
13. LISTICLE Copy density: HIGH Max on-image copy: 25–50 words WHEN TO USE Education and value-driven angles. Best for MOF when you need to communicate multiple benefits, features, or reasons to buy. Works as a mini landing page inside an ad. Strong for considered purchases. DESIGN NOTES Numbered or bulleted list layout. Clear headline at top stating the list premise (“5 reasons why...”, “3 things you need to know”). Each item is a short line with an icon or number. Clean, scannable layout. COPY GUIDELINES Headline (5–8 words) + 3–6 list items (3–8 words each). Each item should be a complete thought that can stand alone. Front-load the most compelling items. This concept CAN carry more text, but each line must be tight. DO + Use a compelling list headline + Keep list items parallel in structure + Limit to 3–6 items + Use icons or numbers for scannability DON’T - Include more than 6 items - Write full sentences for each item - Bury the best points at the bottom - Skip the framing headline 
14. HANDWRITTEN NOTE / WHITEBOARD Copy density: MINIMAL Max on-image copy: 3–10 words WHEN TO USE Personal, founder-led, or behind-the-scenes angles. Works at TOF for authenticity and pattern interruption. Makes the ad feel like a personal message, not a corporate ad. Page 10 Static Concepts — Context Document DESIGN NOTES Handwritten text on paper, notebook, napkin, or whiteboard. Can include the person’s hand or a desk setting. The writing should look natural and slightly imperfect. Background gives context (office, kitchen table, etc.). COPY GUIDELINES One short message, as if someone jotted it down. A question, a bold claim, or a personal statement. The charm is in the brevity and the human feel. DO + Make the handwriting look natural + Keep the message to one short thought + Include a subtle human element (hand, desk, pen) + Use a personal, direct tone DON’T - Write a paragraph by hand - Use perfect calligraphy — it should look casual - Add designed elements that kill the authenticity - Include logos or CTAs on the note itself 
15. INFOGRAPHIC / HOW IT WORKS Copy density: HIGH Max on-image copy: 30–55 words WHEN TO USE Education-heavy angles. Best for MOF/BOF when the product or process needs explanation. Works for SaaS, supplements, services — anything where “how does this work?” is a common question. DESIGN NOTES Step-by-step or visual process layout. Use numbered steps, flow arrows, or icon-based sections. Each step has a small headline and optional one-line description. Clean, organized, and easy to follow top-to-bottom. COPY GUIDELINES Headline (4–6 words) + 3–4 steps with short labels (2–5 words each) and optional one-line descriptions (5–10 words each). The visual flow should guide the eye. Each step must be instantly clear. DO + Limit to 3–4 steps maximum + Use icons or visuals per step + Create clear visual flow (numbered or arrowed) + Write short, action-oriented step labels DON’T - Include more than 4 steps - Write paragraphs per step - Create a confusing visual flow - Skip the headline that frames the process 
16. UGC PHOTO (STYLED AS USER CONTENT) Copy density: MINIMAL Max on-image copy: 0–5 words WHEN TO USE Page 11 Static Concepts — Context Document Authenticity-first angles. All funnel stages. Best when you want the ad to look like a real customer took a photo and shared it. Lowest friction ad format — blends into the feed. DESIGN NOTES Looks like a real photo a customer took with their phone. Natural lighting, slightly imperfect composition, real-world setting. Can include a subtle text overlay or caption, but the photo should work without it. No design elements. COPY GUIDELINES Almost zero on-image copy. Maybe a small caption or tag. The primary text does ALL the talking for this concept. The image’s job is to look real and stop the scroll through authenticity. DO + Use real or realistic-looking photos + Embrace imperfection — it builds trust + Let the primary text carry the message + Show the product in a natural use context DON’T - Add headlines or designed text overlays - Over-edit or filter the photo - Stage it to look like a photoshoot - Forget to optimize the primary text (it’s doing all the work) 
17. PRESS / AS SEEN IN Copy density: LOW Max on-image copy: 5–15 words WHEN TO USE Authority and credibility angles. Best for TOF/MOF when you have real press coverage, features, or notable endorsements. Strong for building trust with cold audiences. DESIGN NOTES Features press logos (Forbes, TechCrunch, etc.), a quote from the publication, or an “As Seen In” bar with multiple logos. Clean, premium layout. The press mention should feel like a genuine editorial endorsement. COPY GUIDELINES Publication name + short quote or just the headline from the article. Maximum 2 lines. The press logos or publication names carry the weight, not your copy. DO + Use real press mentions and logos + Pull the most impressive quote or headline + Keep the layout clean and premium + Include the publication name prominently DON’T - Fabricate press mentions - Overcrowd with too many logos - Add your own marketing copy on top of the press angle - Use outdated press that’s no longer relevant 
18. OFFER / PROMO Copy density: MEDIUM Max on-image copy: 10–25 words Page 12 Static Concepts — Context Document WHEN TO USE Bottom funnel conversion. When you have a specific offer, discount, bundle, or limited-time deal. Best for retargeting and driving immediate action from warm audiences. DESIGN NOTES Bold, prominent offer (percentage off, dollar amount, BOGO, etc.) as the visual hero. Supporting details below (what’s included, deadline, code). Use urgency colors (red, orange) sparingly. Product image secondary to the offer. COPY GUIDELINES The offer headline is everything. Big, bold, unmissable. One supporting line with details or deadline. Optionally add a promo code. Don’t bury the offer in body copy. DO + Make the offer the biggest text element + Include a deadline or urgency element + Show what they get (product image) + Keep it to headline + one detail line DON’T - Bury the offer in paragraph text - Use vague offers (“big savings”) - Forget to mention the deadline - Crowd the design with too many offer details 
19. FOUNDER / FACE-TO-CAMERA Copy density: LOW Max on-image copy: 5–12 words WHEN TO USE Personal brand and trust-building angles. Best for TOF/MOF when a human face drives connection. Strong for founder-led brands, service businesses, and establishing personal authority. DESIGN NOTES Photo of the founder or team member looking directly at camera. Name and title caption. Optional short quote or statement overlaid. The human face is the pattern interrupt. Clean, approachable styling. COPY GUIDELINES Name + title + one short statement or tagline. The face does the selling, the primary text does the telling. Keep on-image copy to an intro — just enough to establish who this person is and hint at what they’ll say. DO + Use a real, approachable photo + Include name and title for credibility + Add one short hook statement + Make the person look trustworthy and relatable DON’T - Add walls of text around the person - Use overly posed or stock-looking photos - Skip the name/title attribution - Make it about the brand instead of the person 
20. CAROUSEL TEASER (SINGLE-IMAGE VERSION) Copy density: MEDIUM Max on-image copy: 10–20 words Page 13 Static Concepts — Context Document WHEN TO USE Curiosity and engagement hooks. Works at TOF/MOF when you want to hint at more content or create a “swipe” feel even in a single image. Good for educational series or multi-benefit messaging. DESIGN NOTES Designed to look like the first frame of a carousel with a visual cue that there’s more (arrow, “swipe” indicator, partial next-card reveal on the edge). Headline hooks the user into wanting to see more. COPY GUIDELINES A strong hook headline + a teaser of what’s coming (“5 things we learned” or “The mistake 90% of brands make”). The copy should create an open loop that makes the viewer need to learn more.
